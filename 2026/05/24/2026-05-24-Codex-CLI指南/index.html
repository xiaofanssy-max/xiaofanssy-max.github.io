OpenAI Codex CLI 使用教程：ChatGPT 终端编程助手完全指南

发表于2026-05-24|更新于2026-05-24|技术

Codex CLI 是 OpenAI 出品的终端 AI Agent，基于 GPT-5 系列模型，支持文件读写、命令执行、Git 操作。最关键的是 —— 你的 ChatGPT Plus 订阅直接就能用，无需额外付费。

一、简介

Codex CLI 是 OpenAI 推出的终端 AI 编程助手，和你在 chatgpt.com 用的网页版不同，它能直接操作你电脑上的项目文件。

定位

对比 说明
vs ChatGPT 网页版 网页版只能聊天，Codex CLI 能改文件、跑命令
vs Claude Code 同为终端 Agent，Codex 优势是 ChatGPT Plus 自带额度
vs GitHub Copilot Copilot 是代码补全，Codex 是全自动 Agent 模式

九、常见问题

网络访问问题？

Codex 运行时需要连接 chatgpt.com 和 api.openai.com。如终端无法访问海外网络，可配置 HTTP 代理环境变量解决。

和 Claude Code 怎么选？

维度 Codex CLI Claude Code
模型 GPT-5 Claude 4
上下文 100 万 20 万
订阅绑定 ChatGPT Plus $20/月 Claude Pro $20/月
IDE 支持 VS Code / Cursor / Windsurf VS Code / JetBrains
桌面 App ✅ codex app ✅ 独立下载

如果你已经在付 ChatGPT Plus，Codex CLI 零额外成本。反之 Claude Code 更适合 Anthropic 生态用户。

代码被 OpenAI 拿来训练吗？

ChatGPT Plus/Pro 企业版不会用你的对话训练模型。API 用户同样默认不训练。
