Crush 终端 AI 助手使用指南：开源免费的多模型编程搭档

发表于2026-05-24|更新于2026-05-24|技术
|浏览量:

Crush 是 Charm 团队开发的开源免费终端 AI 编程助手。最大亮点：接入几乎所有主流大模型，支持国产模型，完全免费无订阅。本文覆盖全平台安装、多模型配置与 Skills 使用。

一、简介

Crush 是一个运行在终端里的开源 AI Agent。它的前身是大名鼎鼎的 OpenCode（已归档），现在由 Charm 团队继续开发，GitHub 24K+ Star。

完全免费 没有任何订阅费，你只需要自己的 API Key
全平台 macOS / Linux / Windows / FreeBSD 全覆盖
开源 代码开放，社区活跃，日更

HTTP 服务 crush serve --http 暴露 API
MCP 客户端 crush mcp serve — 当 MCP 服务器供其他工具调用
VS Code 联动 通过 MCP 协议在 VS Code 中调用 Crush
渠道扩展 支持 Discord / Slack / Telegram 频道交互

十、常见问题

国内用户最佳方案？

Crush + DeepSeek API。全中文友好，不需要海外订阅，价格极低。

网络问题？

Crush 首次启动需要从 GitHub 拉取模型列表，如无法访问可设置代理环境变量。之后日常调用走你配置的 API 地址，只要 API 能通就行。

和原 OpenCode 什么关系？

OpenCode 开发者加入 Charm 团队后重构为 Crush，功能更强、模型更多、已日更维护。OpenCode 已于 2025 年 9 月归档。
