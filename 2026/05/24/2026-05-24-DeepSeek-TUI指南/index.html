DeepSeek TUI 安装与使用指南

发表于2026-05-24|更新于2026-05-24|技术

DeepSeek TUI 是一款终端 AI 编程助手，支持 DeepSeek-V4-Pro/V4-Flash，拥有 1M 上下文窗口，支持文件读写、命令执行等操作。本文介绍 macOS 和 Windows 上的安装与基本用法。

一、安装

前置条件

需要安装 **Node.js 18+**（macOS 和 Windows 通用）：

  • macOS：打开终端，执行 brew install node
  • Windows：打开 PowerShell，执行 winget install OpenJS.NodeJS.LTS

三种模式

按 Tab 键切换：

模式 说明
Plan 只读模式，仅查看和分析，不会修改文件
Agent 自动模式，可读写文件、执行命令（需确认）
YOLO 全自动模式，自动批准所有操作

常用快捷键

按键 作用
Enter 发送消息
Shift+Enter 换行
Tab 切换模式
Shift+Tab 切换推理深度
Esc 中断 AI 回复
? 查看快捷键帮助
Ctrl+C（两次） 退出
