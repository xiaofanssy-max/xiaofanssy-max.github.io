Claude Code 终端 AI 编程助手完全指南：安装配置与实战

发表于2026-05-24|更新于2026-05-24|技术
|浏览量:

Claude Code 是 Anthropic 出品的终端 AI 编程助手，能直接读写文件、执行命令、管理 Git。本文覆盖 macOS 和 Windows 的安装、登录、模型配置与 Skills 使用。

一、简介

Claude Code 是一个运行在终端里的 AI 编程 Agent，基于 Claude 4 系列模型。和网页版 Claude Chat 不同，它能直接操作你电脑上的文件，省去复制粘贴的麻烦。

适用场景

场景 示例
写代码 “给这个项目加一个登录接口”
改 Bug “修复这个报错，把日志也一起看看”
重构 “把整个项目从 JavaScript 迁移到 TypeScript”
文档 “根据代码自动生成 README”
Git 操作 “总结今天的改动，生成 commit 并提 PR”

九、常见问题

首次安装无法下载？

部分地区终端可能无法直接访问海外网络资源。可通过以下方式解决：

  • 配置终端的 HTTP/S 代理环境变量
  • 使用 VPN 或代理工具确保终端能访问 claude.ai 和 api.anthropic.com

中文支持如何？

Claude 4 系列对中文理解很好，直接说中文需求即可。

和 Claude 网页版有什么区别？

网页版：手动复制粘贴 → AI 回答 → 再复制回去。
Claude Code：AI 直接读写你电脑上的文件，全自动执行。
